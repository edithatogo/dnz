# DigitalNZ source archive and integration evidence

This dataset package contains source-grounded software, notebooks, metadata inventories, and evidence used by the `dnz` DigitalNZ v3 integration hub.

## Scope

The package may include checked-in source trees and generated metadata inventories described by [`SOURCE_ARCHIVE_CARD.md`](../../SOURCE_ARCHIVE_CARD.md). It does not claim to redistribute the underlying digital objects aggregated by DigitalNZ.

## Rights and provenance

The repository's own source is MIT-licensed where marked. Rights in provider metadata, item descriptions, thumbnails, and linked digital objects remain with the originating provider and collection. Users must inspect the provider's rights statement before reuse. The package therefore records provenance and scope, not a blanket reuse licence.

The API contract is grounded in the [DigitalNZ developer documentation](https://digitalnz.org/developers). The repository preserves source links and raw provider values where available.

## Intended use

- Reproducible development and testing of DigitalNZ API integrations.
- Audit-friendly metadata and provenance review.
- Offline research workflows over checked-in source material.

## Limitations

- This is not a complete mirror of DigitalNZ.
- Provider availability, rights, and metadata can change independently of this repository.
- No DOI or external registry acceptance is claimed until the target service supplies an identifier or acceptance record.
