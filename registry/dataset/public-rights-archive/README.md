# Public DigitalNZ rights inventory

This directory is generated from `digitalnz/facets/rights.csv`. Each CSV is
an aggregate rights-statement inventory with a weighted record count.

It is not an item-level licence register and does not include, authorise, or
redistribute underlying DigitalNZ objects, thumbnails, or provider payloads.
Use the original provider record and its current rights statement before
reusing any individual object.

Publicly approved groups are public-domain/no-known-restriction, CC BY,
CC BY-SA, CC BY-NC, CC BY-NC-SA, CC BY-NC-ND, and other open/conditional
wording. The remaining groups are exported separately for review rather than
silently treated as reusable.
